## 0.17.29

Added a server setting to hide the one-time login notice shown when Iron & Nouveau and Ars 'n Spells are installed together.

In `irons_nouveau-server.toml`:

```toml
[compatibility]
show_ars_n_spells_notice = false
```

The default is `true`, preserving the existing once-per-player, per-world notice. While disabled, the notice is not marked as read, so players who have never seen it can receive it if the setting is enabled again. Restart the game or server after editing the configuration.

Available for Minecraft 1.21.1 NeoForge and 1.20.1 Forge.

### 中文

新增共装提示开关：在 `irons_nouveau-server.toml` 的 `[compatibility]` 下设置 `show_ars_n_spells_notice = false`，可关闭与 Ars 'n Spells 共装时的首次登录提示。

默认开启，保留每位玩家每个世界仅提示一次的规则。关闭时不写入已读标记；重新开启后，未读玩家仍可收到提示。修改后请重启游戏或服务器。
