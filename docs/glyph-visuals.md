# 原生法术图标

Iron & Nouveau 0.17.21 / Conflux 0.1.25，双版本统一。

所有 Iron 效果与弹射物替换增强通过 `GlyphVisuals` 返回原生 `AbstractSpell.getSpellIconResource()`。不复制图标，不把本体语义放进 Core。默认 GUI 使用 Ars 底板、分类外框和 75% 中心；手持仍使用原物品模型。

配置：`config/ars_conflux-client.toml`。`frame_enabled` 控制外框，`provider_icons` 控制原生法术图标；后者关闭恢复旧卷轴等中心，两者同时关闭恢复旧版 GUI。颜色模式 `ARS_TYPE` / `UNIFORM` / `CUSTOM`，比例 `center_scale`；完整 API 见 [Core 文档](../../Ars-Conflux/docs/glyph-visuals.md)。

NeoForge 开发预览：`:runClient -PiconPreview=true -Pstandalone=true`。忽略的 `libs/icon-preview/` 可放入灾变与其附属，检查原生三维渲染和淡化。预览类属于 gameTest 源集，不进入发行包；保存截图后自动退出。
