# 通用施法框架（0.9.0）

0.17.0 起，以下公共执行机制委托 Ars Conflux；Iron 只保留原生法术适配。本文的旧类名仍是兼容入口，新增载体应使用 Core 注册 API，详见 [接入记录](ars-conflux.md)。

该文档描述已实现部分。定时吐息、持续血吸光束与电刑、瞬时冰霜射线和目标光柱已经接入；玩家按住引导输入、传送锚点仍未实现。

## 分层

| 层 | 入口及职责 |
| --- | --- |
| 魔符声明 | `NativeFormAugment` 选择形态；`BridgeGlyph` 选择目标或位置效果 |
| 权限与组合 | `NativeCasting.validate`、`GlyphAccessEvent` 检查组合、法术启用、学习和执行权限 |
| 数值 | `CastModifiers` 保存待结算等级和速度；`CastPlan` 保存最终等级、强度、期限 |
| 空间与生命周期 | `AimSource`、`CastAim`、`CastSession`、`CastExecution` 提供公共 start/tick/close |
| 轨迹 | `CarrierProfiles` 声明载体能力；`ProjectileExecution` 使用 Iron 物理；`ArsTrajectoryExecution` 委托 Ars 轨迹 |
| 命中 | `ProjectilePayload` 配置简单载荷；`ComplexProjectilePayload` 调用原生爆炸／状态回调；`ComplexImpacts` 管理接续去重 |
| 目标与位置 | `SpellAdapter` 应用到目标；`LocationSpellAdapter` 每个命中执行一次，避免按范围内目标重复生成整个区域 |
| 费用 | `TriggerMana` 检查、预留、执行并提交每次费用；`ProjectileVolley` 限制实际分裂数，散布仍由 Ars 生成 |
| 长期资源 | `EffectResources` 管理所有权、租期、权限、数量和逐轮计费；`StatusBilling` 管理雷暴状态的施法者账本 |
| 触发几何 | `TriggerGeometry` 在 Ars 上下文保存飞行方向，克隆和当前运行的延迟上下文可继承；原生形态接续提供当前执行器方向 |
| 吐息 | `BreathPose` 按实体优先级决定发射位置与方向；`BreathExecution` 使用公共会话管理期限与维持费用；`ConeState` 同步发射源，保持原生 owner 为施法者 |

## 吐息实现

`BreathAdapters` 使用原有 `LocationSpellAdapter`，每次触发创建一个 `CastSession`，四种原生锥形实体共用 `BreathExecution`。第一次付费由 `BridgeGlyph` 预留并提交，后续每 10 tick 通过同一个 `TriggerMana` 账本支付。吐息缺蓝时结束整个会话，不沿用回响和已有区域的等待回蓝策略。

原生锥体的 tick 硬编码跟随 owner，火焰子类还在父类 tick 之前引燃方块。因此只对标记为托管的锥体替换这两处调度，由执行器更新发射姿态和原生 ConePart 碰撞体，并调用原生命中回调。普通 Iron 吐息保持原有逻辑。客户端通过同步的发射实体 ID、相对偏移、范围与实体姿态绘制相应 Iron 粒子；发射实体不是伤害所有者。

生物触发以命中位置相对该生物的偏移为起点，并持续读取其朝向。位置触发保存固定起点和飞行方向快照。方向作为通用几何上下文传递，不从施法者之后的视角推断；无需改变怪物目标、身体朝向或 `MagicData`。

龙息产生的子区域通过已有 `EffectResources` 继承施法者、等级和支付来源，独立执行其期限和后续费用。吐息本身不保存到世界 NBT，死亡、换维度、权限丢失和服务端停止时由公共会话清理。

## 费用顺序

Ars 的施放方式原本先生成实体、再结算蓝量。本模组仅在包含 Iron 魔符的施放中，将原来的 `expendMana` 提到施放方式调用前，仍走原入口，保留 Ars 'n' Spells 的支付提交。

随后读取可支付的分裂数量。`ArsSplitBudgetMixin` 只在本次施放范围内调整形态所属 `SpellStats` 的分裂计数，不改存储的法术配方、速度、方向或其他普通法术。附属的现有分裂循环同样读这个计数；持续环绕和回响按激活付费，不在生成外观时裁数量。

`TriggerMana` 不先扣后退款：先预留，执行返回成功才提交。嵌套 Iron 效果检查时扣除外层预留，防止内外层同时支出同一份蓝。失败不付 Iron 费用，Ars 已经发生的起始施放费用仍保留。

## 命中与持续资源

普通原生形态对成功伤害的目标接续 Ars；复杂爆炸共享一次命中作用域，成功伤害／状态的目标按 UUID 去重。对于溅射载体，复杂爆炸按一个原生溅射轮运行一次。普通未转换 Iron 实体不会进入本模组的计费或接续作用域。

子区域继承原施法者、魔符、法术等级和支付来源，避免直到后来爆炸时丢失账本。所有被管理实体写入租期 NBT，区块重载后可以恢复权限和到期检查。无法重新取得原有装置账本时，使用所有者的 Ars 蓝池；当前主要支持玩家和生物施法来源，不保证任意装置专属资源持久恢复。

同一持续实体同一轮只付一次，嵌套原生伤害调用不再次收费。无蓝不执行该轮，后续回蓝可恢复；寿命继续流逝。普通召唤单位的自主攻击不逐次收费。持续资源内部脉冲不重复触发创建它的 Ars 外层效果链。

## 扩展边界

增加遵循 `EntityProjectileSpell`／`SpellResolver` 契约的载体，优先补 `CarrierProfiles` 能力声明。自己直接伤害、查询原载体世界身份或不通过解析器上报命中的附属需要专门适配。

增加普通目标状态用 `SpellAdapter`，增加命中位置区域、召唤或定时吐息用 `LocationSpellAdapter`。射线可以沿用吐息已使用的动态 `AimSource` 与独立 `CastExecution`，继续复用计费和清理；仍需定义射线碰撞、输入及终止条件，不能直接调用任意法术 `onCast`。

## 统一等级

`SpellLevels` 通过 `SpellProgress` 读取基础等级：玩家使用个人制作记录，创造使用原生最高等级，生物使用一级；再计算增幅加一、减弱减一、最低一级。它读取各自法术段的实际强化列表，避免把 Ars 的浮点输出倍率和装备输出修正误当作原生等级；Iron 原生装备法强仍由其参数公式读取。形态在转换时建立 `CastPlan`，效果由 `Resolution.level()` 提供同一规则，双方均不截断到原生最高等级。

效果适配器调用最终等级的原生公开参数；私有的北极熊生命、幽匿触手伤害和雷暴状态强度通过窄范围 Invoker 调用，不再叠加旧 25% 输出倍率。召唤数量与状态时长也根据原生等级变化，独立的 Ars 延时和范围在其后处理。

施放前与真正触发时都检查最终等级权限；持续会话、子实体租期和雷暴状态记录该等级，用于后续费用和权限。0.7.0 前已有的实体继续使用原先保存的一级，旧雷暴没有等级字段时按一级恢复。`GlyphAccessEvent` 接口保持兼容；0.8.0 起玩家还须有个人制作记录（创造豁免）。Path-To-Zero 0.8.4 移除了最终等级的墨水权限检查。


## 0.15.9：烟火与自身护盾修复

- 烟火四射继续使用 Iron 的 `ExtendedFireworkRocket`。该实体的 `tick` 不负责引爆，生成成功后调用原生 `shoot` 入口，恢复爆炸伤害、施法者归属、烟花客户端事件与实体移除。生成失败时不触发爆炸。方块命中点沿表面法线外移 0.25 格，避免爆炸中心陷入方块。
- 自身护盾使用 Iron 同款 `RaycastBuilder`：从施法者眼部出发，沿视线最多 3 格，遇到方块截断。Ars 明确指定的远程位置仍采用原命中坐标，不统一增加高度或移回玩家身边。无需额外魔符附属提供头部起点。
- 针对性回归覆盖烟火伤害／归属／移除、自身护盾眼部定位／墙面截断、远程护盾位置。客户端烟花视觉仍需人工确认；服务端使用原生事件。

## 原生射线与光柱

`NativeRayGeometry` 为冰霜射线的完整原生调用提供作用域内的空间输入，射线搜索范围从实际起点计算，避免远程触发误用施法者的包围盒。原生伤害、冻结、实体生成和粒子逻辑均直接保留。作用域通过 `finally` 恢复，不改动玩家的 `MagicData`。

电刑复用 `BreathExecution`；受管锥体仅替换位置、碰撞计费和寿命，仍运行电刑子类生成分支电弧的客户端 tick。`NativeElectrocuteRenderingMixin` 只调整受管实体的朝向和范围，保留全部原生绘制层。烈阳射线使用目标位置适配器创建原生实体，原生实体独立完成蓄势与爆发，并标记延迟命中已支付，避免再次收费。
