# 魔符名称键修复（2026-11-03）

本地 Ars 5.13.1 编译依赖与实例 5.13.3 的 `AbstractSpellPart.getLocalizationKey()` 均读取 `<注册命名空间>.glyph_name.<魔符路径>`。新增条目只写 `ars_nouveau.glyph_name` 或 `item.<命名空间>`，不能满足这个真实调用；名称物品本身也通过魔符的 `getLocaleName()` 获取文字。

本批在中英文资源中补齐实际命名空间，保留已有兼容条目，不修改 Java 行为。`verifyGlyphNameKeys` 检查中英文的规范名称键、空值/明显乱码；对 Iron 同时按全部共享配方核对，资源打包和源码包任务都依赖此检查。Goety 当前 142 个规范名称键原本齐全，其独立项目补同样的构建检查，不为本批虚增一个游戏版本。

整合包另外在已有全局汉化包中补入 13 个新魔符的规范名与物品名兜底（26 条），译名来自作者自己的原生语言文件。Goety 五个名称的原生资源本来存在；尚未得到具体异常显示文字，未将其归因为与本项目相同的漏键。

仅做资源/发行包核对，不启动 Minecraft。两端构建与哈希见 `glyph-name-keys-build.json`；没有自动上传 CurseForge。
