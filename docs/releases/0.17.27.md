# Iron & Nouveau 0.17.27

## Glyph rendering and JEI fixes

- Use native spell icons for held, dropped and displayed glyph items, as well as the existing GUI icons. Older glyphs no longer fall back to scroll models outside the GUI.
- Register the referenced native spell icons in the item texture atlas, fixing missing purple-and-black textures on automatically generated glyphs. If an upstream icon is missing, the item model falls back to the Ars blank glyph.
- Show every native scroll level as an alternative ingredient in glyph recipes, so higher-level scrolls can also find their recipes through JEI's uses search. Crafting still accepts any positive-level scroll for the matching spell, regardless of who made it.

## New since 0.17.25: optional native self-casting

- Automatically generate effect glyphs and Scribe's Table recipes for external Iron spell addons using standard deferred spell registration. Existing dedicated glyph adaptations keep their behavior.
- These generated glyphs support **player self-casting only**. The native spell controls its targeting and direction; this is not a generic projectile or remote-target adaptation.
- Keep native cast checks, continuous casting, cancellation and cooldowns. Trigger and pulse costs use the configured resource account without double charging. Existing spell-level and learning settings also apply.
- Generated glyph descriptions explain the self-casting restriction. Set `native_self.enabled = false` to disable this fallback.

Available for Minecraft 1.21.1 / NeoForge and Minecraft 1.20.1 / Forge. Ars Conflux is required; Iron spell addons remain optional.
