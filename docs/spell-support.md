# 法术支持与边界（0.16.0）

此分支使用 Iron 1.20.1-3.16.3、Ars 4.12.7；魔符附属为可选联动。完整注册清单见 [README](../README.md)。当前 99 个魔符，不代表全量 Iron 法术库；[核对清单](spell-audit.md) 区分明确暂缓的类别与仍待适配的候选。等级与学习方式见 [配置说明](configuration.md)。

| 机制 | 已接入 | 实现边界 |
| --- | --- | --- |
| 简单投射物 | 原有七种形态 | 等级最后结算；普通载体原生物理，附属委托轨迹 |
| 爆炸 | 火球术、爆裂赤焰箭 | 原生爆炸事件与破坏配置；溅射每轮只爆炸一次 |
| 状态爆炸 | 腐蚀喷吐、雪球术 | 使用原生破甲／冰冻公式；成功状态接续 Ars |
| 子区域 | 毒箭射击、岩浆炸弹、雪球术 | 子实体继承计费来源与租期；逐轮付费 |
| 目标状态 | 治疗、神圣守护、橡肤、急迫、迟缓、枯萎术、强效治疗、净化 | 复用现有目标效果接口，按最终原生等级计算状态、治疗及费用 |
| 束缚 | 纠缠根须 | 原生根须实体和骑乘束缚，尊重不可束缚标签 |
| 目标攻击 | 落雷、邪术冲击波、连锁闪电 | 使用 Ars 命中结果；邪术冲击波只处理一次瞬时攻击 |
| 自主攻击实体 | 圣灵、萤火虫群 | 原生目标和追击行为，所有权和期限由租期管理 |
| 持续区域 | 雷暴、黑洞、治愈之环、幽匿之触 | 每轮检查蓝量；没蓝跳过，原持续时间照常流逝 |
| 召唤 | 恼鬼、亡灵、骏马、利剑、北极熊 | Ars 命中点为召唤中心，所有者是原施法者；不使用 Iron 重施栏 |
| 吐息与电弧 | 火焰吐息、毒雾喷射、龙息、刺骨寒风、电刑 | 原生锥体和命中效果，独立发射源；固定时长，每轮扣蓝，缺蓝终止 |
| 新增状态与目标 | 10 种原生增益、生命祝福、变色、献祭、噬咬、针灸、反制、冰墓、末影箱 | 状态基准取施法者，状态及附加次数写入实际目标；专属目标条件保留 |
| 新增区域与位置效果 | 地震、暴风雪、毒液迸溅、引力裂隙、灼烧、热浪、寒潮、雷电冲击、落冰、盾牌、替罪羊、践踏、獠牙、音爆、神圣重击 | 原生实体拥有期限与账本；延迟子实体继承信息；一次性命中不重复付费 |
| 新增形态 | 血斩、凋灵之首、苦力怕头投掷 | 保留原生伤害来源、吸血／爆炸；普通血斩的特殊碰撞入口接续 Ars；凋灵之首速度先计算原生等级再叠加 Ars 加速 |
| 发射与连锁 | 星海落瀑、万箭齐发、苦力怕之环、尖牙漩涡、烈焰风暴、再生云域 | 每轮发射／治疗与击杀连锁计费；子弹命中不重复收费 |
| 反弹与追踪形态 | 闪电球、烈焰追踪弹幕 | 标准弹射物保留原生反弹／追踪，后续闪电伤害轮次付费；其他载体保留 Ars 轨迹 |
| 动作 | 暗影斩击、烈焰冲锋、飞升、伏特打击 | 仅实体目标，接收者移动，伤害和属性取原施法者；原生接触效果单次冲刺费用，不逐接触重复收费 |
| 武器与地形 | 炽焰斩击、地狱浮现、冰霜尖刺、烟火四射 | 使用 Ars 位置与方向，不创建原生重施状态；缺少攻击属性的生物按零武器加成 |
| 采掘 | 幽冥锤、点石成杵 | 仅玩家；冒险／出生点／破坏事件保护；限制采掘工作量 |

已加入冰霜射线、电刑、烈阳射线。冰霜射线是原生瞬时射线；电刑是原生持续锥体；烈阳射线是目标位置的延迟光柱，采用和星海落瀑一致的位置入口。传送术、回溯、传送门、口袋维度等空间迁移仍未接入。

召唤利剑使用 Iron 原生自主武器生物；不会假设它只围绕施法者旋转。强效治疗以目标生命上限为基准；净化遵守原生友方和免疫规则。原生酸蚀球当前实体命中代码使用固定 3.5 格范围，保留其行为。持续实体自己的原生期限可能短于租期；租期提供清理上界，不会强行延长原生实体。

附属仍为可选依赖。回响轨迹通过原解析器周期触发，排除自己的 Iron 外观实体，移除已转换轨迹的 20 次计数上限。环绕与回响的每次有效激活都支付魔力，后续 Iron 效果另付自身费用；没有给持续输出一次付费永久生效的特权。

验证包括服务端注册／配方、实际碰撞、散射预算与角度、持续区域缺蓝和恢复、召唤中心及原生复杂命中回调；不包含客户端外观或正式存档实机体验。

新增法术保留既有资源上界：针灸最多 64 根、獠牙列最多 64 个、獠牙环最多 240 个、方向性冲击最多 128 格。它们限制单次生成的工作量，不限制法术计算等级；状态放大仍受 Minecraft 状态等级的数据范围限制。魔法护盾会先遵守其原生 400 tick 寿命，不会因延时强行延长实体自身期限。

冰霜射线调用原版完整攻击，仅以作用域替换射线起点／命中结果，保留原生双层材质、冻结、命中 `ICY_FOG`、末端 `SNOWFLAKE` 与音效。电刑使用原生 `ElectrocuteProjectile` 和完整渲染器，不用普通粒子代替光束；命中仍走原生电击粒子回调。烈阳射线使用原生 `SunbeamEntity` 与完整光柱渲染器，保留蓄势声、爆发声、余烬和冲击波。瞬时射线及光柱不接受延时增强；电刑接受延时、增幅与范围。

0.16.0 的 4 项专用服务端 GameTest 已通过：远程冻结射线／原版施法隔离、方向与墙体阻挡、电刑跟随及空蓝停止、光柱蓄势／延迟命中／一次计费。日志 `build/ray-tests.log`。客户端原生渲染调用已按字节码核对，尚未启动客户端实机验证。
