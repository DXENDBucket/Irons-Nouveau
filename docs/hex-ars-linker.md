# Hex-Ars Linker 可选联动

从 0.15.4 起，安装 Hex-Ars Linker（`hex_ars_link`）时自动启用弹射物适配。Hex Casting、Linker 及其依赖仍需自行安装；未安装时本模组照常工作，不加载任何 Hex 类，也不打包第三方模组。

Linker 常规施法入口原本就经过 Ars 的发射逻辑；指定位置发射入口会自行创建普通 Ars 弹射物，绕过通常的转换钩子。现在本模组在实体加入世界时识别 Linker 的 `PatternResolver`，通过同一 `NativeCasting.convert` 转换普通弹射物。没有 Iron 形态魔符的弹射物保持原状；非 Linker 解析器不受此兼容分支影响。

转换保留实际出发点、方向、速度、施法者、法术等级、效果接续、解锁检查及实际触发耗蓝。正常 Ars 发射流程已经转换的弹射物不会再次转换。未解锁或缺蓝时不会生成 Iron 弹射物。

## 吟唱和冷却边界

此次兼容仅补齐弹射物转换。常规主动施法沿用现有吟唱和冷却；Linker 指定实体与指定位置入口直接解析，仍不经过主动吟唱／冷却。吟唱也不会暂停整个 Hex 程序等待完成。不能把这次适配理解为所有 Hex 施法入口的完整吟唱、冷却或异步编排兼容。

1.21.1 实验组合使用 Hex Casting `0.12.0-devel-pre-53`、Linker `1.21.1-0.9.5.2.pre53.fix2`。Hex 预览版的客户端平台服务加载修复仍在独立实验补丁中，不属于本模组；弹射物转换不再需要实验补丁。

2026-10-06：移除实验补丁中的转换事件后，使用本体 0.15.4 运行三个集成 GameTest 均通过：指定实体治疗及权限／蓝量限制、Hex 法术物品的普通弹射物施法、Linker 指定位置发射。未扩展到所有 Hex 施法入口或多人场景。

上游实现：[Linker 1.21 分支](https://github.com/YukkuriC/HexArsLinker/tree/1.21)。
