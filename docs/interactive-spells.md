# 交互法术（0.17.8）

本版先实现火墙术（`glyph_wall_of_fire`）。Conflux 负责输入端点、工具身份、会话生命周期与 Ars 游标续接；火墙的节点数、地面选择、总长度、伤害、粒子、实体、费用和原生冷却在 Iron & Nouveau 中定义。无需让其他法术提供者依赖 Iron。

## 使用

1. 用同一手持工具施放含火墙术的 Ars 编排。触摸／弹射物命中点成为第一个节点；自身触发按当前视线选点。
2. 继续使用同一术式，按当前视线追加节点，最多三个。每个有效新节点重新开始两秒等待时间。
3. 节点用尽、达到总长度或两秒未继续操作时完成；仅有一个节点时按原生规则补选当前视线位置。
4. 潜行使用取消。换工具、换选中的术式、死亡或离开原维度也会取消。

火墙生成时复用 Iron 的原生实体、分段碰撞、外观和 240 tick 寿命；原生伤害及长度读取最终等级和施法者属性，增幅仍每个提高一级，不引入卷轴等级上限。范围增强追加最大总长度。

## 编排与费用

第一个火墙节点暂停其后的编排。正常完成后，后续魔符在最后的节点命中结果处执行一次；前面的魔符不重新执行。取消不执行剩余内容。

初次成功启动收取一次 Iron 费用，后续选点不重新收取整条 Ars 术式费用、不吟唱。玩家的火墙原生冷却延迟到会话结束，包括主动取消；同编排的其他 Iron 法术保留已有冷却规则。正在选点时的输入优先路由，不被已收费后剩余蓝量或其他节点的 CD 拦截。

本版要求有效的手持来源；装置／无工具自动化入口不能建立火墙选点会话。没有新增怪物自动规划火墙路径。绑定武器可接入相同输入入口，非玩家绑定武器仍保留既有本地冷却规则。Core 的 API 允许后续提供者采用自己的绑定、费用与输入策略。

## 验证范围

定向服务端检查覆盖首次付费及暂停、实际 Ars 主动入口追加节点、前缀不重放、后缀只执行一次、超时补点、潜行取消、来源变化取消和玩家原生冷却延迟。测试 namespace 为 `irons_nouveau_interaction`，共享检查用于 1.21.1 NeoForge 与 1.20.1 Forge。客户端粒子、原生火墙外观及连续操作手感仍需游戏内观察。

这是首批多次交互接入。传送门、念力、其他原生重施与按住持续施法尚未因此实现；具体剩余内容见 [法术核对](spell-audit.md)。

0.17.8 发布检查：两个平台各通过全部 4 项交互检查及现有单元测试；Core 独立环境通过 3 项。100 份共享配方生成结果一致，四个发行包均检查了许可证、新 API／魔符、物品模型及不含测试类；Forge 发行包完成重映射。未运行全量 GameTest 套件或客户端画面测试。
