# 不祥灵火球（0.17.41）

## 玩法

新增 `irons_nouveau:glyph_ominous_fire_orb`，为位置效果魔符，默认一级。原生卷轴等级不适用于此 Boss 独有能力。

| 基准 | 数值 |
| --- | --- |
| 魔力消耗 | 600，成功放置时支付一次 |
| 吟唱／冷却 | 2 秒／25 秒，沿用既有开关、Iron 属性与 Conflux 缩减 |
| 蓄能／引信 | 1 秒／25 秒；蓄能后才允许受击摧毁 |
| 爆心基础伤害 | 120，再吃原生火焰法强、Ars／Conflux 伤害成长 |
| 爆炸半径 | 12 格，保留原生距离衰减和视线判断 |
| 火球生命 | 150 |
| 获取 | 抄写台：神圣灵魂碎片 ×1＋魔源宝石 ×1，经验 55 |

强化／削弱每单位改变基础伤害 ±2；扩散每单位增加半径 2 格（最终 1–32）；延长／缩短时效改变引信，沿用现有 `1 + 0.5 × durationMultiplier`、0.1–8 倍规则。被摧毁后直接消散，不爆炸。爆炸成功命中后保留原生灼尽叠层，不破坏地形。

这是放置效果：后续 Ars 效果按原有顺序在触发点继续执行，不推迟到火球爆炸时。不添加投掷型替换、饰品能力或新的多次交互规则。

## 原生依据与边界

核对实际 Iron 3.16.3 的 NeoForge 1.21.1／Forge 1.20.1 发布 JAR，均存在 `OminousFireOrbEntity`、对应 Renderer 和 `FieryExplosionParticlesPacket`。原初受火者的放置／投掷 Goal 使用 500 tick 引信、150 火球生命、120–160 伤害及 37.5–50 半径；本魔符采用其低端爆心伤害，将半径独立收在 12，配以 600 Mana 和 25 秒冷却，不接入随 Boss 失血增强的 Goal。

直接使用原生实体、原生伤害循环、成长／旋转外观、声音、粒子、爆炸数据包、视线、距离衰减、反魔法和摧毁反馈。图标运行时引用原生神圣灵魂碎片，不复制任何 Iron 实现或图片，不生成隐藏 Boss。

`AbilityOrbMixin` 仅为带本附属能力租约的火球进入延迟伤害作用域，校验真正施法者、到期时间和魔符权限；延迟爆炸不再扣一次创建费。保留伤害所有者，排除施法者及 Conflux 友军。原生火球把所有 Infernal Allies 当同队；此判断仅对本附属火球换成真实所有者的友军关系，避免玩家火球把敌对炼狱生物当作友军。原生 Boss 生成的火球走原分支。

`EffectResources.executeOnce` 复用现有租约与持久化归属，爆炸实际发生前再次检查，避免实体 tick 早于统一租约清理时造成迟到伤害；不强加载区块。原生 NBT 保存 Age，重新加载时恢复该年龄；晚进入追踪范围的客户端通过一项仅初始化时更新的同步时钟修正原生 tickCount，避免倒计时外观从零重播。普通原生火球时钟为禁用值，保留其原行为。

新魔符同样提供 Conflux／Instinct 提示（attack、area、self/enemy/position），专门适配提示总数为 109；不为生物自动安装 AI。它没有对应卷轴，使用前一批 Boss 能力相同的材料制作／Ars 学习规则。
